## 超小型 SSG 「Route」
これについて書きたかっただけまであります笑  
めちゃめちゃ久しぶりに Go 言語を使って開発してみました！やっぱりね、うん。Gopher が可愛い。  
あのマスコットを考えた人は天才だと思う。そんなことは置いておいて、技術ですね、技術。  
一番重要なコア部分、Markdown → HTML のパーサー (っていうのかな...？) は goldmark という OSS を使用しました。  
こちら、非常に強力なライブラリとなっておりまして、シンプルな記述で実装できました。本当にありがとうございます...  
Route で売りにしている点は、機能を最小限にしているところです。  
例えば「groute init」「groute new '明日は休み！'」「groute gen '明日は休み！'」 と実行するだけで gen/ 配下に index と articles が自動で生成されます。  
それだけだと競合と変わらん...？え、でもね！でもね！ほら！ここはおもしろいとおもうよ！「groute new 」を実行したタイミングで md/ 配下に index.md を生成しているんです！  
わあお！なんと index.md に好きな記述をしてやることで！！！！簡単に index ページをカスタマイズできる！っていうね。
はい。そういうことです。  
いまの時代、競合さんに勝てることなんてないんですよ、ははは... 。
